## How to Compile and Run

Open the integrated terminal in Visual Studio Code and navigate to the relevant source file's directory.

### C

```bash
gcc firstprogram.c -o firstprogram.exe
.\firstprogram.exe
```

### C++

```bash
g++ firstcppprogram.cpp -o firstcppprogram.exe
.\firstcppprogram.exe
```

These commands assume GCC and G++ are installed and available in your terminal's PATH. Replace the filenames with the source file you want to compile.
